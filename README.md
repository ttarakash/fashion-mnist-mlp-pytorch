# Классификация одежды FashionMNIST: полносвязная нейросеть (PyTorch)

Многослойный перцептрон (MLP) на PyTorch для распознавания 10 категорий одежды по изображениям 28×28.

## Данные
- FashionMNIST: 60 000 изображений для обучения и 10 000 для теста, 10 классов.
- Обучающая выборка разделена на train (54 000) и validation (6 000).
- Тетрадь скачивает данные сама через `torchvision.datasets`.

## Что сделано
1. **Подготовка данных:** загрузка через `torchvision`, разбиение на train/validation, `DataLoader`, просмотр изображений.
2. **Архитектуры:** MLP с одним, двумя и тремя скрытыми слоями, классы `nn.Module`.
3. **Обучение:** собственный цикл обучения (оптимизатор, функция потерь, графики loss и accuracy по эпохам).
4. **Сохранение модели:** запись и загрузка весов (`state_dict`).
5. **Эксперименты:** сравнение глубины сети и гиперпараметров (learning rate, размер батча, число эпох).

## Результаты (5 эпох)

| Модель | Train | Validation | Test |
|---|---|---|---|
| 1 скрытый слой, 64 нейрона | 87,8% | 85,6% | 85,2% |
| 2 скрытых слоя (128 → 128) | 89,7% | 88,4% | 87,2% |
| **3 скрытых слоя (128 → 64 → 32)** | 89,4% | 87,7% | **87,3%** |

## Выводы
Трёхслойная сеть даёт лучшую точность на тесте при небольшом разрыве между train и validation, то есть без сильного переобучения.
